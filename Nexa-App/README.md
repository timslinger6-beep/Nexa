Nexa App 0.2
============

Einfache 3D-Editor-Anwendung für das Nexa-Projekt.

Aktuelle Funktionen:

- echte 3D-Szene
- Kamera
- Würfel
- Kugel
- Zylinder
- Objekte auswählen
- Objekte löschen
- Objekte bewegen
- Objekte drehen
- Objekte skalieren
- Objektliste
- Eigenschaften
- Projekte speichern
- Projekte laden

Start:

    python .\src\main.py
